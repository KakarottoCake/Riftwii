RiftWii {{VERSION}} is out, a small update. {{RELEASE_URL}}

* **Big game libraries use less memory.** Updates and game details now download straight to the SD card, so RiftWii no longer runs out of memory and restarts when you have hundreds of games.
* **Settings has new buttons**, in the Wii Menu's style.

If updating kept restarting RiftWii on a big library, copy boot.dol from the zip to sd:/apps/riftwii/ by hand once.

Sending logs (you don't need to take out your SD card): in RiftWii go to Settings > Help > Send a problem report, scan the QR code or copy the link, and post it here.
